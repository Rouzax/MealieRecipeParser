# Tools (schema.org tool) - optioneel

## Wanneer opnemen
- Neem top-level "tool": ["..."] alleen op als tools expliciet genoemd worden in de bron (titel/tekst).

## Voorbeelden
- oven, koekenpan, wok, braadpan, steelpan, pan, grill, barbecue/smoker
- blender, staafmixer, keukenmachine, mixer
- garde, rasp, zeef, deegroller
- bakplaat, ovenschaal, bakvorm, springvorm

## Let op
- Geen aannames: noem geen tools die niet expliciet genoemd worden.
