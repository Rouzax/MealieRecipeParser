# Description Rules (schema.org Recipe.description)

## Doel
`description` is een **korte, gerecht-gerichte** samenvatting voor digitaal gebruik.
Geen persoonlijke verhalen of anekdotes.

## Lengte
- 1–3 zinnen (richtlijn: 250–450 tekens).
- Geen lijstjes, geen emoji.

## Wat wél opnemen
- Wat het is (soort gerecht).
- Herkomst/keuken **alleen als expliciet** in bron (titel/tekst/cuisine).
- Smaak/karakter (1–2 kenmerken: kruidig/romig/fris/rokerig/etc.).
- Optioneel: 1 korte serveerhint als dit in bron staat of logisch uit context (geen aannames).

## Wat níet opnemen (altijd verwijderen)
- Ik/jij-vorm, persoonlijke verhalen, reis-/restaurant-anekdotes.
- Boek-meta of pagina-verwijzingen.
- Tijden/hoeveelheden/procesbeschrijvingen (die horen in stappen/ingredienten).

## Als bron een description heeft
- Herschrijf/opschonen: behoud alleen gerecht + herkomst (expliciet) + smaak.
- Verwijder anekdotes en irrelevante zinnen.

## Als bron géén description heeft
- Maak een neutrale 1–2 zinnen samenvatting op basis van titel + ingrediënten + bereidingswijze.
- Geen nieuwe feiten toevoegen die niet uit de bron volgt.

## Taal
- `description` moet **volledig Nederlands** zijn.
- Als de bron description (deels) Engels/anders is: vertaal en herschrijf volgens deze regels.
